# Calories burnt prediction

A simple machine learning project that predicts the calorie label in an exercise dataset. The notebook walks through the analysis, and a separate desktop app lets you try the trained model.

**[Read the notebook](Calories_burnt_prediction_clean.ipynb)** · **[View the GUI script](calorie_calculator.py)** · **[Explore the separate research project](https://github.com/Moobakr/calorie-lab-research)**

## What the project does

- Checks the data, removes the identifier and one duplicate, and explores relationships between measurements.
- Compares Linear Regression, Lasso, Ridge and XGBoost on the same train/test split.
- Tunes XGBoost with five-fold cross-validation and explains predictions using SHAP.
- Saves the tuned pipeline for a Tkinter app with grouped inputs, a calorie estimate and a feature contribution chart.

The saved notebook run has **test MAE 1.034** and **test RMSE 1.476** for tuned XGBoost on 3,000 test records. These are errors against the recorded labels in this exploratory split, not independently measured calorie burn.

## Run locally

Use **Python 3.12**, the version used to check this project. Download or clone the repository, then open a terminal in its folder:

```powershell
python -m pip install -r requirements.txt
```

1. Open `Calories_burnt_prediction_clean.ipynb` in VS Code or Jupyter.
2. Select the Python environment where you installed the dependencies and **run all cells**. Keep the notebook's working directory set to this folder; the CSV path is `exercise.csv`.
3. The notebook creates `calorie_model.joblib`. Keep it beside the GUI script, then run:

```powershell
python calorie_calculator.py
```

Enter the measurements and click **Calculate estimate**, or click **Try a fictional example**. The GUI requires a desktop session with Tkinter, which is included in the standard Windows Python installer. Load only the model generated by this notebook.

## Interpretation and next steps

The dataset's original collection, label construction, units and licensing are unverified. The target is interpreted as kcal per session for this example. SHAP percentages describe model contributions, not confidence or causal effects; this is an educational demo, not a validated health measurement.

The separate **[Calorie Lab research repository](https://github.com/Moobakr/calorie-lab-research)** extends this starting project with controlled input comparisons, uncertainty analysis and a browser demo. Its evaluation is separate from this notebook. Earlier versions of this project remain in Git history.
