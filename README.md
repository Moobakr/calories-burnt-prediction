# Calories burnt prediction — original notebook

This repository preserves the original calorie-prediction notebook, the starting point for my later research project.

**[Open the original notebook](Calories_burnt_prediction_project.ipynb)** · **[Explore the research project](https://github.com/Moobakr/calorie-lab-research)**

## What is here?

The original notebook explores a supplied calorie dataset and builds a prediction model. It is retained as a record of the project's starting point; its original code and outputs are unchanged.

## What changed in the research project?

The separate **[Calorie Lab research repository](https://github.com/Moobakr/calorie-lab-research)** adds controlled input comparisons, reproducible evaluation, uncertainty and subgroup analysis, and a public browser demo. Its README explains the main findings in plain language and links to the supporting evidence.

## Data and interpretation

The CSV is not included: its original collection, label construction, units and licensing remain unresolved. Notebook results describe agreement with recorded labels and do not establish physiological accuracy or health benefits. Running the notebook requires the matching local data and suitable Python dependencies.

The repository's history is preserved. Research work previously published here now has a separate home; use the research repository when sharing the completed study.
